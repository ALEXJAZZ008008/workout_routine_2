{\fontsize{9.7}{10.7}\selectfont\bfseries PROGRESSION}\par\vspace{0.08cm}
{\fontsize{6.45}{6.95}\selectfont
3 sets (+1 total): 8/8/8 $\to$ 9/8/8 $\to$ 9/9/8 $\to$ 9/9/9.\quad
2 sets (+1 total): 8/8 $\to$ 9/8 $\to$ 9/9.\\[-5.5pt]
10--20 (+2 total): 10/10 $\to$ 11/11 $\to$ 12/12. Continue the same pattern to the top of each range.\\[-5.5pt]
Effort: $\sim$1 RIR on working sets; final set may reach 0--1 RIR. Last rep hard but technically clean.\\[-5.5pt]
At ceiling: increase to the next load and plan the range minimum. Actual reps may initially fall below the range.\\[-5.5pt]
If the planned target is missed, record actual and repeat the same target until achieved; then resume normal progression.\\[-5.5pt]
A target missed at the programmed pace counts as a miss; do not add rest solely to achieve it.\\[-5.5pt]
Individual stalls are tolerated while other exercises progress; do not reset or alter that exercise automatically.\\[-5.5pt]
Recovery: if $\geq$50\% of exercises miss planned progression or regress for 3 consecutive sessions, skip the next scheduled session.
}
\end{tcolorbox}
